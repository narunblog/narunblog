## Project overview
- **Purpose**: Provide a single, version-controlled place to describe who narunblog is, what they build, and how to get in touch.
- **Visibility**: Whatever is written here is rendered verbatim at the top of the GitHub profile, making it the most visible personal landing page.
- **Workflow**: Update this file locally, preview the Markdown, and open a PR to publish any changes.

## How to update
1. Edit `README.md` locally or in the browser.
2. Preview the Markdown (`ctrl+shift+v` in VS Code or use `gh markdown-preview`).
3. Commit your changes with a descriptive message (e.g., `docs: refresh profile intro`).
4. Open a pull request summarizing what changed and why; once merged, the profile updates instantly.
